# 隐私说明

Space Tracker 的扫描快照是本地数据，不是适合公开发布的测试数据。快照可能包含：

- 扫描根目录和相对路径；
- Reparse Point 的链接目标；
- 无权限或特殊文件的绝对路径；
- 文件数量、大小和修改时间。

因此：

1. 将快照放在仓库之外的目录，例如 `D:\space-tracker-snapshots`。
2. 不要把真实扫描快照、验证目录或构建产物提交到 Git。
3. 发布问题或日志时，先替换用户名、工程盘符、应用名称和具体文件名。
4. 公开文档只使用 `C:\Users\YourName`、`D:\space-tracker` 等通用示例。

仓库根目录的 `.gitignore` 已覆盖常见快照、临时文件、验证目录和 `target/` 构建产物，但提交前仍应检查暂存区内容。
